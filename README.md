# 📅 Tropicana SPB — Telegram-бот записи клиентов в салон красоты

Бот предлагает клиенту выбрать день и **свободный тайм-слот с 10:00 до 22:00 с шагом 30 минут**,
затем услугу, имя и телефон — и создаёт запись. Клиент может посмотреть и отменить свои записи,
**за 3 часа до визита приходит напоминание**, а администратор получает уведомления о новых
записях/отменах и может увидеть все записи командой `/bookings`.

## Стек технологий

| Компонент          | Технология                                   |
|--------------------|----------------------------------------------|
| Язык               | Python 3.12                                  |
| Telegram-фреймворк | [aiogram 3](https://docs.aiogram.dev) (async, FSM, inline-клавиатуры, request_contact) |
| ORM                | SQLAlchemy 2.0 (asyncio)                     |
| База данных        | SQLite (достаточно для этого проекта)        |
| Планировщик        | APScheduler 3 (напоминания о визите)         |
| Конфигурация       | pydantic-settings (env-переменные)           |
| Контейнеризация    | Docker + docker-compose                      |

## Структура проекта

```
app/
├── main.py            # точка входа (polling + scheduler)
├── config.py          # настройки из ENV (в т.ч. SERVICES, ADMIN_CHAT_ID)
├── keyboards.py       # inline-клавиатуры: дни, слоты, услуги, телефон, подтверждение
├── scheduler.py       # фоновые напоминания о визите (каждые 10 минут)
├── db/
│   ├── models.py      # Booking (+service, phone, reminder_sent) + partial unique индекс на слот
│   └── session.py     # async engine / init_db (с авто-добавлением новых колонок)
└── handlers/
    ├── start.py       # /start, /help, меню, «О салоне»
    ├── booking.py     # сценарий записи, «Мои записи», уведомления админу
    └── admin.py       # /bookings <ADMIN_SECRET> — список записей на неделю
```

## Быстрый старт (локально)

```bash
pip install -r requirements.txt
cp .env.example .env          # впишите BOT_TOKEN от @BotFather
python -m app.main
```

## Запуск в Docker (SQLite)

```bash
cp .env.example .env          # BOT_TOKEN=..., ADMIN_SECRET=..., ADMIN_CHAT_ID=...
docker compose up -d --build
```

База хранится в volume `bot_data` (путь внутри контейнера `/srv/app/data/salon.db`)
и переживает пересборку/перезапуск контейнера.

Только образ без compose:

```bash
docker build -t tropicana-bot .
docker run -d --name tropicana-bot --env-file .env -v bot_data:/srv/app/data tropicana-bot
```

## Сценарий клиента

1. `/start` → главное меню: «📅 Записаться», «📋 Мои записи», «ℹ️ О салоне».
2. Выбор дня (сегодня … +7 дней). На «сегодня» прошедшие слоты скрыты.
3. Кнопки свободных слотов: `10:00 10:30 11:00 … 21:30` (по 4 в ряду).
4. **Выбор услуги**: «Услуга 1 · 30 мин», «Услуга 2 · 30 мин» (названия и длительности
   задаются в `.env`, новые добавляются по аналогии).
5. Имя → **телефон**: кнопка «📱 Отправить телефон» (request_contact) или ввод текстом,
   пропустить — `/skip`.
6. Подтверждение → запись создана; админ получил уведомление; за `REMINDER_HOURS_BEFORE`
   часов придёт напоминание.

## Услуги (изменение и добавление)

В `.env` (или ENV контейнера):

```
SERVICES=Услуга 1|30;Услуга 2|30
```

Формат: `Название|длительность_в_минутах`, разделитель услуг — `;`. Чтобы добавить услугу —
допишите `;Услуга 3|45` и перезапустите контейнер. Названия «Услуга 1/2» замените на реальные.

## Напоминания и уведомления админу

- **Напоминание клиенту**: APScheduler каждые 10 минут ищет активные записи, начинающиеся
  в окне «за REMINDER_HOURS_BEFORE часов», отправляет сообщение в чат клиента и ставит
  флаг `reminder_sent` (не отправит дважды, переживает рестарт контейнера).
- **Уведомления админу** (`ADMIN_CHAT_ID` — ваш числовой Telegram ID, узнать у @userinfobot):
  🆕 новая запись (имя, телефон, услуга, дата/время, Telegram ID клиента) и 🚫 отмена записи.
- `/bookings <ADMIN_SECRET>` — все активные записи на 7 дней с телефонами и услугами.

## Админ-команды

| Команда | Описание |
|---|---|
| `/bookings <секрет>` | Список активных записей на неделю (нужен `ADMIN_SECRET`) |

## Заметки

- Защита от «гонки» за слот: частичный уникальный индекс `UNIQUE(booking_date, booking_time)
  WHERE status='ACTIVE'` + проверка перед созданием записи.
- Если клиент заблокировал бота — напоминание/уведомление логируется и не ломает процесс.
- Часовой пояс салона: `TIMEZONE=Europe/Moscow`.
